好在哪

  • 一行 36px 封顶：默认态再也不会把对话区挤没，元信息全部搬进抽屉
  • 抽屉 overflow: auto + max-height: 100vh：执行记录再长也能滚到底，不会像现在这样被卡片裁掉
  • 条本身 flex: none 排在滚动区之外，对话怎么滚都在原位；状态色只留左侧 3px 竖条，不再有整块渐变底
  • 暂停原因、阻塞原因作为第二行只在 paused/blocked 时出现，正常运行时只有一行

代价

  • 看「执行记录」要点开抽屉、再点开折叠项，比现在直接展开多一步
  • 抽屉遮挡右侧对话（抽屉宽 380px，可改成压暗背景的浮动面板）
