好在哪

  • 最省空间：常态只有 26px 的细线，只有状态点、状态文字、轮次、耗时和一个 ⋯
  • 悬停出浮卡看全部指标，不点击也不占位；⋯ 菜单里放 继续 / 清除 / 详情
  • 细线与对话区用 1px 分隔线区分，保留状态色的左端 3px 竖条
  • 详情同样是自带滚动的抽屉，长短内容都不会顶坏布局

代价

  • 关键信息（轮次用尽、为什么暂停）要在悬停后才知道，扫一眼不够
  • 悬停浮卡在触控板/触屏上不友好，移动端要退化成点击展开
