设置 → 模型：模型库 + 角色分配 — 四套候选

同一个功能：模型库（多条 OpenAI 兼容端点，可增删改、逐条测试）+ 角色分配（主模型 / 守门员 / 漏洞评审 / 指挥官，各从库里挑一条）。 配色、圆角、字号、表格行高全部取自控制台现有的 style.css（.page-card / .ws-panel / .tag / .mode-switch），选中的方案可以直接落地，不需要新的视觉语言。

四套用的数据完全相同：MiniMax-M3.1-Flash（主模型）、DeepSeek-V3.1（守门员）、GLM-4.7（漏洞评审）、本地 vLLM（指挥官）、备用中转（未使用）。 差别只在操作顺序：A/B 以「模型」为中心，C 是经典主从，D 以「角色」为中心。
