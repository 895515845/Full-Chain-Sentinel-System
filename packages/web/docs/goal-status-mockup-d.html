好在哪

  • 沿用控制台台账语言：无圆角、无渐变，只有 3px 状态竖条 + 上下分隔线，和 POC 库台账同一族
  • 轮次做成 3 段细分格（▮▮▯），一眼看出预算还剩几格，比 1/3 更快
  • 「执行记录」就地展开，但整块 max-height + overflow: auto：内容再长也只在自己的框里滚，永远挤不掉对话
  • 暂停原因写进同一条头部的右侧，不额外占行

代价

  • 展开执行记录时会占掉对话区一部分高度（有上限、可滚，但仍是占用）
  • 视觉比现在的圆角卡片“硬”，如果控制台整体偏柔和，需要接受这个风格差
