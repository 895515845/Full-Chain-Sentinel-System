# SPEC · UI 与交互

> 归属模块：`web/`（React SPA，构建产物 embed 进二进制）
> 状态：v1.0。M0 只交付布局 + 空态；M1/M2/M3 逐页填充。

---

## 1. 设计原则

1. **信息密度优先**：参照 Burp / ZAP / Charles，而不是 SaaS 后台。行高 28px，表格不放大留白。
2. **键盘可达**：所有高频操作有快捷键，Tab 序合理，焦点环清晰可见（`outline: 2px solid #34d399`）。
3. **零 canvas / 零 WebGL / 零图片**：全部真实 DOM，可被无头浏览器与读屏器完整解析。
4. **状态在 URL 里**：页面、选中项、过滤条件都可深链；刷新不丢。
5. **稳定 testid**：交互元素与关键容器必须带 `data-testid`，文案改动不影响自动化。
6. **中文文案**：代码标识、HTTP 头、URL 保持原样。

## 3. 页面规格

### 3.1 History（`/history`）

| 区域 | M0 | 最终（M2） |
|---|---|---|
| 工具栏 | 方法下拉/Host 输入/搜索/刷新，disabled | 真实过滤、debounce 300ms、条件进 URL |
| 代理开关 | 无 | 右上角「启动代理」+ 端口显示 + CA 未安装提示条 |
| 列表 | 空态 `history-empty` | 虚拟滚动表格：时间/方法/URL/状态/长度/耗时；行点击选中并高亮 |
| 详情 | 无 | 右侧抽屉，Tab：Request / Response / Raw / Hex / TLS / Timings；"发送到 Repeater" |
| 快捷键 | — | `↑/↓` 移动选中，`⌘/Ctrl+Enter` 重放，`⌘/Ctrl+F` 聚焦搜索，`Delete` 删除 |

空态文案：**暂无抓包** / 启动代理后，浏览器访问的 HTTP/HTTPS 请求会实时出现在这里。

### 3.2 Repeater（`/repeater`）

```
┌─ 标签栏 ────────────────────────────────────────────────[+ 新建]────────┐
│ tab1 ×  tab2 ×                                                          │
├──────────────────────────────┬──────────────────────────────────────────┤
│ 请求                          │ 响应                                      │
│ [Raw | 结构化]  [脚本 ▾]      │ [Pretty|Raw|Hex|Headers]  [复制]         │
│ ┌──────────────────────────┐ │ ┌──────────────────────────────────────┐ │
│ │ GET / HTTP/1.1           │ │ │ 空态：尚未发送请求                    │ │
│ │ Host: example.com        │ │ │                                       │ │
│ └──────────────────────────┘ │ └──────────────────────────────────────┘ │
│ 状态行提示 / 警告徽标          │ 200 OK · 1.8 KB · 87 ms                  │
├──────────────────────────────┴──────────────────────────────────────────┤
│ [发送 ⌘↵]  [取消]                                  目标: https://...    │
└─────────────────────────────────────────────────────────────────────────┘
```

- 左右分割可拖动，比例记忆（localStorage），默认 45/55。
- 发送中：按钮变「取消」，响应区顶部细进度条（仅 3 个阶段：连接/TLS/等待）。
- 响应显示：状态码按类着色（2xx 绿 / 3xx 蓝 / 4xx 黄 / 5xx 红）；`error` 非空时显示错误卡片（code + 中文说明 + "如何解决"）。
- 警告（`cl_mismatch` / `te_and_cl` / `obs_fold`）在请求区底部显示黄色徽标，hover 出详情。
- 未保存 tab 关闭需确认；草稿 500ms 防抖 PATCH。
- 快捷键：`⌘/Ctrl+Enter` 发送，`⌘/Ctrl+T` 新 tab，`⌘/Ctrl+W` 关 tab，`⌘/Ctrl+S` 立即保存。

### 3.3 Scripts（`/scripts`）

- 左列 240px：脚本列表（名称 + 语言徽标 js/py + 启用开关），底部「新建」。
- 右侧：名称输入 + 语言选择 + CodeMirror 6 编辑器（JS/Python 语法高亮）+ 钩子勾选（onRequest / onResponse / onAssert）+ 「保存」「试跑」。
- 底部日志抽屉：`[12:00:01] info signed ok`，错误行红色；试跑结果 `ok/fail` 徽标 + 耗时。
- 文档内联：右侧折叠面板列出可用 API（`req.headers.get()`, `ctx.vars`, `helpers.hmac` …）。

### 3.4 Settings（`/settings`）

分卡片：**服务信息**（listen / 版本 / commit / 平台 / 数据目录 / uptime）、**代理**（M2：端口、CA 下载与安装引导、诊断按钮）、**脚本运行时**（JS 超时、Python 解释器路径）、**存储**（保留天数/条数、清空历史、导出全部）、**关于**。

M0：服务信息真实渲染自 `/api/health`，其余卡片显示"即将提供"。

## 5. Agent / 无头可测性（硬性）

| # | 要求 |
|---|---|
| A1 | 关键元素 testid 稳定：`nav-*`、`page-*`、`health-pill`、`history-empty`、`repeater-send`、`repeater-response-empty`、`scripts-empty`、`settings-info`；新增交互必须同时加 testid |
| A2 | 语义标签：`<nav>` `<main>` `<header>` `<h1>` `<table>`；按钮一律 `<button>`，禁用用真 `disabled` |
| A3 | 首屏文本即真实内容，不依赖动画/懒加载/骨架屏才出现 |
| A4 | 所有列表有可读的空态/错误态，不出现空白页 |
| A5 | 无自定义右键菜单、无拖拽-only 操作（拖拽必须有等价按钮/输入） |
| A6 | 深链可用：`/history?host=x`、`/repeater/tab_123`，刷新后状态一致 |
| A7 | 无 `alert()` / `confirm()` 阻塞式弹窗（用内联确认条） |
| A8 | 控制台零报错、零未捕获 Promise rejection |

CI 用 Playwright 冒烟：打开 `/` → 断言 `page-history` → 切到 Repeater → 断言 `repeater-send` 存在 → Settings 断言版本号非空。
