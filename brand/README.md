# 品牌图标候选

给「全链哨兵 Full Chain Sentinel System」的图标候选，8 个方案，纯几何、单色。

- `icons/*.svg`：交付文件，`viewBox="0 0 64 64"`，颜色一律用 `currentColor`，所以在深色控制台、浅色文档、白底 README 里都能直接用，不需要改文件。
- `preview.png`：8 个候选在深色底上的样子（控制台是暗色 UI，这张最接近实际观感），4 列 2 行，行优先对应文件名 01 到 08。
- `preview-light.png`：同样 8 个，白底深色墨，看形状更清楚。
- `preview-sizes.png`：16 / 24 / 32 / 48 px 四行，用来判断小尺寸下是否还认得出来（侧边栏图标、favicon 都在这个量级）。

## 八个方案

| 文件 | 名称 | 想法 |
| --- | --- | --- |
| `01-shield-link.svg` | 盾与链环 | 盾形轮廓里放一个链环：防护 + 链条，最直白 |
| `02-beacon.svg` | 哨塔与信号 | 塔顶一盏灯加两侧信号弧，哨兵在值守 |
| `03-radar.svg` | 雷达扫描 | 同心圆加扫描扇面，持续监视 |
| `04-node-chain.svg` | 链路节点 | 三个节点连成一条线，中间节点挖空成环 |
| `05-chain-route.svg` | 全链路径 | 折线路径加三个节点，对应攻击链/全链路推进 |
| `06-eye-link.svg` | 哨眼与链环 | 眼形，瞳孔挖成一个环 |
| `07-hex-link.svg` | 六边盾与链环 | 六边形盾，内部链环，比 01 更硬朗 |
| `08-chain-ring.svg` | 链条环与中心盾 | 四段链环围成一圈，中心一个盾 |

## 选中之后

图标本身是独立的 SVG，可以直接当 favicon，也可以把 path 贴进前端组件（`packages/web/webui/src/components/icons.tsx` 里就是这种做法）或登录页的 `<img>`。确定后我再接进控制台的侧边栏、登录页和浏览器标题。
